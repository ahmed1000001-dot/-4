Canteen Pro v4 — النسخة المعدلة حسب طريقة عمل المقصف

المنطق المعتمد:
1) المشتريات: تدخل اسم المنتج + عدد الكراتين + إجمالي سعر شراء الكمية.
2) التطبيق يعرف عدد القطع في الكرتونة وسعر بيع القطعة من بطاقة المنتج.
3) يحسب لكل منتج:
   - عدد القطع
   - قيمة البيع المتوقعة
   - الربح المتوقع
   - نسبة الربح % على تكلفة الشراء
4) تسجل إجمالي المبيعات اليومية مرة واحدة فقط.
5) حساب المورد: إجمالي الفواتير - المدفوع مع الفاتورة - التسديدات اللاحقة.
6) المصروفات: فطار، بقشيش العمال، إيجار المدرسة، أخرى.
7) المسحوبات: أحمد عبدالعظيم / محمد إبراهيم، نقدي أو عيني محسوب بالجنيه.
8) الإيرادات الأخرى: بيع الكراتين الفارغة وغيرها.
9) الجرد: تدخل عدد القطع المتبقية من كل صنف، ويحسب قيمتها بسعر البيع.
10) مراجعة الجرد:
    الربح المتوقع المتبقي = الربح المتوقع + الإيرادات الأخرى - المصروفات - المسحوبات
    صافي الربح الموجود = (المبيعات + الإيرادات الأخرى - ما دُفع للمورد - المصروفات - المسحوبات)
                         + قيمة الجرد - مديونية المورد
    الفرق = صافي الربح الموجود - الربح المتوقع المتبقي
    صفر = تمام، سالب = عجز، موجب = زيادة.

التطبيق أوفلاين بقاعدة SQLite، ويدعم النسخ الاحتياطي والاسترجاع.
